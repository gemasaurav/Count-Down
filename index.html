One-time setup (GitHub Token)

1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token (classic) → give it gist permission only
3. Copy the token
4. Open this HTML file in Notepad / VS Code
5. Find YOUR_GITHUB_TOKEN and replace it with your token
6. Upload the file again to your GitHub Pages repo
